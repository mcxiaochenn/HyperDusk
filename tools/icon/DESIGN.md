构图（v2）：暮色主题，以月牙与一个星芒形成简洁、居中、留白充足的组合。

背景：108×108dp 满幅不透明垂直渐变，0 / 0.45 / 0.72 / 1 处依次为 #0B1026、#1E1B4B、#4A2E5C、#C0714F。地平线辉光圆心 (54, 104)、半径 46dp，颜色 #F2B27A，alpha 从中心 0.42 随半径线性降至边缘 0，以 alpha 合成叠加到底色。

月牙：外圆 (52, 50)、半径 23dp，减去圆心 (61, 41)、半径 20dp 的圆形 mask；填充从外圆顶部 y=27dp 的 #FFF6EA 垂直渐变到底部 y=73dp 的 #FFD9B0。

星芒：中心 (77, 31)，横向 12×3.2dp、纵向 3.2×12dp 两个胶囊交叠，圆头半径 1.6dp，填充 #FFF1DC。

适配：月牙几何包围框在 (29, 27)..(75, 73)，星芒在 (71, 25)..(83, 37)，均位于中心 72dp 安全区 18..90 内。单色层共用同一组 mask，RGB 全部为纯白，透明度保留抗锯齿。输出边长为 size 时，高分辨率画布边长为 4×size，所有 dp 坐标和半径乘以 4×size/108，再以 LANCZOS 降采样；最终每 dp 对应 size/108 像素。

矢量版：共用几何与配色常量，背景矩形加径向渐变圆、两个圆构成相减遮罩、两个圆角矩形构成星芒，不使用手描路径。PNG、SVG、Android 三层资源与 XML 的产物路径及生成流程保持原样，圆形预览保留振铃 alpha 夹回 0/255 的修复。

48dp 风险：星芒的 3.2dp 笔画缩至约 1.42px，最容易受像素对齐和抗锯齿影响而显得偏软。
